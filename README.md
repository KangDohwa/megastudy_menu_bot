# 메가밥 · 메가스터디 구내식당 메뉴 봇

서초 메가스터디 구내식당의 점심 메뉴와 주간 메뉴표를 디스코드에서 확인할 수 있습니다. 메뉴표는 [메가푸드 블로그](https://blog.naver.com/megafs01)에서 가져옵니다.

## 서버에 봇 초대하기

1. **서버 관리** 권한이 있는 디스코드 계정으로 [메가밥 초대 링크](https://discord.com/oauth2/authorize?client_id=1564916236846899202&integration_type=0&scope=bot%20applications.commands&permissions=35840)를 여세요.
2. 봇을 추가할 서버를 선택하고 **채널 보기**, **메시지 보내기**, **파일 첨부** 권한을 승인하세요.

## 메뉴 조회

| 명령어 | 설명 |
| --- | --- |
| `/오늘점심`, `/오점` | 오늘의 Self 점심 메뉴를 보여줍니다. |
| `/내일점심`, `/내점` | 내일의 Self 점심 메뉴를 보여줍니다. 금요일에 입력하면 토요일 휴무를 안내합니다. |
| `/이번주` | 이번 주 전체 메뉴표를 이미지로 보여줍니다. |
| `/다음주` | 다음 주 전체 메뉴표를 이미지로 보여줍니다. |

날짜는 한국 시간 기준이며 한 주는 일요일에 시작합니다. 토요일이나 일요일의 점심 메뉴를 조회하면 휴무를 안내합니다.

## 평일 자동 발송

자동 발송을 설정·조회·해제하려면 **서버 관리** 권한이 필요합니다. 메뉴를 받을 텍스트 채널에서 원하는 시각을 한국 시간 기준 24시간제(`HH:mm`)로 입력하세요.

| 명령어 | 설명 |
| --- | --- |
| `/오늘점심자동 시간:11:30` | 평일 오전 11시 30분에 이 채널로 오늘 점심 메뉴를 보냅니다. |
| `/오늘점심자동` | 예약된 시간과 발송 채널을 확인합니다. |
| `/오늘점심자동 시간:해제` | 자동 발송을 중지합니다. |

서버마다 예약을 하나씩 둘 수 있습니다. 다시 설정하면 해당 서버의 발송 채널과 시간이 바뀝니다. 같은 서버에서 누군가 `/오늘점심`이나 `/오점`으로 이미 메뉴 이미지를 받았다면 그날 자동 발송은 건너뜁니다.
